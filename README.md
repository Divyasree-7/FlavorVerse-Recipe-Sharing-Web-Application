# FlavorVerse
World Recipe Discovery Platform with AI Chef Assistant

FlavorVerse is a responsive frontend web application that enables users to explore global cuisines through an interactive and visually structured interface.
The platform features curated recipes from multiple countries and includes an AI-powered Chef Assistant for real-time cooking guidance and smart suggestions.
This project was developed as part of a web development internship and demonstrates strong frontend architecture, UI design, and JavaScript-driven interactivity.

## Features

🌍 Explore 48+ recipes across multiple cuisines
🤖 AI Chef Assistant (Claude API integration with fallback responses)
🔍 Real-time search across recipes and ingredients
🛒 Dynamic grocery list generator
⏱️ Interactive cooking timer
🌗 Light & Dark theme toggle (persistent across sessions)
🌐 Multi-language support
📱 Fully responsive mobile-first design
📝 Recipe submission form with image preview
🎥 Embedded video walkthroughs

## AI Integration

The AI Chef Assistant integrates with the Claude API to provide cooking-related responses.
For secure production deployment, a backend proxy is recommended to protect API keys.
